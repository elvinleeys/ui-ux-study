# 오늘의 과제 시작

## 절차
1. `docs/progress.md`의 "현재 상태"를 읽는다.
2. 상태에 따라 분기한다.
   - `진행 전`: `docs/curriculum.md`에서 현재 Day를 찾아 안내하고, 상태를 `진행 중`으로, 날짜를 기록한다. 새 브랜치 `day-NN-<주제>` 생성을 제안한다.
   - `진행 중`: "이번 Day에서 남은 일"을 보여 주고 이어서 할 첫 단계를 제안한다.
   - `제출됨`: 과제를 진행하지 말고 "새 세션에서 `/ui-review NN`을 실행하세요"라고만 안내한다.
   - `통과`: 현재 Day를 다음 Day로 올리고 `진행 전` 절차를 따른다.
   - `재도전`: "보완 과제"를 먼저 안내한다. 보완이 끝나면 다시 `/submit`.
3. "다음에 보완할 1가지"가 있으면 오늘 과제와 어떻게 연결할지 한 줄로 말한다.

## 안내 형식 (짧게)
```
Day NN · <주제> · 예상 <시간>
목표: <한 줄>
오늘 순서:
1. ...
2. ...
지난 리뷰에서 보완할 점: <한 줄 또는 없음>
첫 단계부터 시작할까요?
```

## 지킬 것
- 커리큘럼을 임의로 바꾸지 않는다. 바꾸고 싶으면 사용자에게 제안만 한다.
- 공식 값 측정은 사용자 몫임을 해당 Day라면 다시 알려 준다.
- 세션 끝에 사용자가 그만한다고 하면 "이번 Day에서 남은 일"을 progress에 갱신한다.
